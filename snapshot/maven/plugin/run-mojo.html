piranha:run

Full name:

cloud.piranha.maven:piranha-maven-plugin:25.1.0-SNAPSHOT:run

Description:

This goal will deploy your web application, start Piranha and wait for it. It echoes the Piranha console back to you for your convenience.

Attributes:

  • Requires a Maven project to be executed.
  • The goal is not marked as thread-safe and thus does not support parallel builds.

Required Parameters

Name Type Since Description
<runtimeDirectory> String - Stores the runtime directory.
Default: ${project.build.directory}/piranha
User Property: piranha.runtimeDirectory
